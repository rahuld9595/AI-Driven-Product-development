# Augmented Product Development Lab

The lab converts the sustainable-practice model into small, evidence-based exercises. Each round
increases capability while keeping human ownership, code quality, and security controls central.

## How to use the lab

1. Choose the current maturity round.
2. Complete one activity at a time in a non-sensitive sample repository or approved environment.
3. Capture evidence in a pull request, test report, architecture note, or the reference index.
4. Reflect on what was useful, what required human correction, and what should become a reusable
   team standard.

## Ground rules

:::warning Use safe material
Exercise examples must be synthetic, public, or explicitly approved. Do not place confidential
business information, customer data, credentials, or internal source code into this public
repository.
:::

- A human reviews and approves every change the exercises produce.
- An activity is not complete until its evidence is linked in the
  [reference index](../reference.md).
- Do not skip a round. Later rounds assume the guardrails earlier rounds produce.
