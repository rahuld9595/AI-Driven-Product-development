# 3. GWT Story Skill

## Objective

Translate product intent into unambiguous, testable behavior using Given-When-Then scenarios, and package the procedure as a reusable skill.

## Steps

1. Start with a narrowly defined user need.
2. State the precondition using Given.
3. Define the user or system action using When.
4. Define the observable outcome using Then.
5. Review for edge cases, permissions, failure modes, and measurable acceptance.

## Evidence of completion

A committed skill definition and a story converted with it, with open questions raised rather than assumed.
