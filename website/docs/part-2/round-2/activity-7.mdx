# 7. TDD with Claude

## Objective

Use AI assistance inside a test-driven workflow: express expected behavior first, implement minimally, and refactor only with a passing suite.

## Steps

1. Define a small behavior through a failing test.
2. Ask for implementation options constrained by the repository rules.
3. Implement the smallest change that makes the test pass.
4. Run the relevant suite.
5. Refactor only after behavior is protected.
6. Review changes for correctness, complexity, error handling, and security.

## Evidence of completion

A commit sequence showing tests first, implementation next, and validation results.
