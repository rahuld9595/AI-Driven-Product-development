# 1. Code Reviews and Pull Requests

## Objective

Use AI assistance to improve pull-request clarity and review preparation while retaining human accountability for design, correctness, security, and merge decisions.

## Steps

1. Prepare a small, single-purpose change.
2. Draft a summary explaining intent, affected components, risk, and validation.
3. Request targeted feedback against explicit acceptance criteria.
4. Address feedback with traceable commits.
5. Record final validation evidence.

## Evidence of completion

A pull request showing a focused description, a review checklist, test results, and human approval.

## Record it

Add the artifact link to the [reference index](../../reference.md) as `R2-01`.
