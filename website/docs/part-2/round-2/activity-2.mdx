# 2. CLAUDE.md to Rules

## Objective

Convert durable repository guidance into concise, version-controlled rules that help AI assistants and human contributors work consistently.

## Steps

1. Identify conventions that should be stable across contributions.
2. Separate universal rules from task-specific instructions.
3. Cover testing, formatting, dependency, security, and documentation expectations.
4. Keep rules short, specific, reviewable, and current.

## Evidence of completion

A guidance file plus a pull request showing the rules improved a concrete change.

## Record it

Add the artifact link to the [reference index](../../reference.md) as `R2-02`.
