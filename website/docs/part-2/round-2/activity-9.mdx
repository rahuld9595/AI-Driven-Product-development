# 9. DRY Audit

## Objective

Use AI-assisted analysis to find duplicated logic, documentation, configuration, or test setup, then apply DRY thoughtfully rather than over-abstracting.

## Steps

1. Identify repeated code or process fragments.
2. Compare duplication cost against abstraction cost.
3. Extract only stable, genuinely shared behavior.
4. Preserve readability and local reasoning.
5. Validate that refactoring does not change intended behavior.

## Evidence of completion

A focused refactoring pull request with tests and a rationale for why the abstraction is justified.
