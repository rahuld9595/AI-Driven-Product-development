# 6. Agent + Skills

## Objective

Define bounded agent responsibilities and reusable skills with clear inputs, outputs, permissions, escalation paths, and evaluation criteria.

## Steps

1. Choose a narrow, repeatable task with a well-defined outcome.
2. Define allowed actions and prohibited actions explicitly.
3. Represent reusable procedures as skills or structured instructions.
4. Require approval before consequential or irreversible actions.
5. Evaluate outputs against deterministic checks and named review criteria.

## Evidence of completion

A committed agent definition exercised on a real task, with its escalation path demonstrated.
