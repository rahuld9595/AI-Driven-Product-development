# 10. Bonus: Custom Review Instructions

## Objective

Define context-specific review instructions that help reviewers and AI tools concentrate on the risks most relevant to a change.

## Steps

1. Identify the change type and its most material risks.
2. Specify checks for correctness, tests, security, performance, accessibility, reliability, or data handling as applicable.
3. State which decisions require human approval.
4. Keep instructions specific enough to verify and short enough to reuse.

## Evidence of completion

A review instruction set applied to a real change, with the risks it surfaced.
