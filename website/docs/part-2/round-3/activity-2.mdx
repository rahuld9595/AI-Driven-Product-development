# 2. Deterministic Verification

## Objective

Replace subjective review of generated output with checks that pass or fail.

## Steps

1. List the qualities you currently judge by eye.
2. Convert each into a lint rule, schema, or test where possible.
3. Accept that some qualities remain human judgment and name them.
4. Wire the automatable checks into the pull-request pipeline.

## Evidence of completion

A CI pipeline that rejects output failing the encoded criteria.

## Record it

Add the artifact link to the [reference index](../../reference.md) as `R3-02`.
