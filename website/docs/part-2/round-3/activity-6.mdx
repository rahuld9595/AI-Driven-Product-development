# 6. Round 3 Retrospective

## Objective

Decide what should stay automated and what should be handed back.

## Steps

1. Review each automation's error rate and intervention count.
2. Retire automation whose supervision cost exceeds its saving.
3. Record the criteria used for that decision.
4. Publish the surviving set as team standard.

## Evidence of completion

A written keep-or-retire decision per automation, with the evidence behind it.

## Record it

Add the artifact link to the [reference index](../../reference.md) as `R3-06`.
