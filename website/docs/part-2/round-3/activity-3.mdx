# 3. Custom Commands

## Objective

Package a repeated multi-step request into one invocable command.

## Steps

1. Identify a sequence you type more than once a week.
2. Capture its inputs, steps, and output format.
3. Commit it as a named command in the repository.
4. Have a second person run it unchanged and report friction.

## Evidence of completion

A committed command another contributor ran successfully without coaching.

## Record it

Add the artifact link to the [reference index](../../reference.md) as `R3-03`.
