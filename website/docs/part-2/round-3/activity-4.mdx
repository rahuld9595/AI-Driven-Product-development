# 4. Automate a Proven Workflow

## Objective

Promote one manually validated workflow into governed automation.

## Steps

1. Select a workflow already executed manually several times with stable results.
2. Document owner, trigger, inputs, outputs, and failure modes.
3. Implement with least-privilege access.
4. Emit logs or metrics sufficient to reconstruct any run.
5. Define what causes it to stop and hand off to a human.

## Evidence of completion

An automation with a named owner, a recorded run, and a demonstrated recovery path.
