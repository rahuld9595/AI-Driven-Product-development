# 5. Small Reviewable Change

## Objective

Scope a change small enough to review in a few minutes.

## Steps

1. Pick a change touching no more than a couple of files.
2. Write acceptance criteria before implementing.
3. Implement with AI assistance, constrained by the recorded conventions.
4. Update or add tests covering the criteria.

## Evidence of completion

A diff a reviewer can assess without asking clarifying questions.

## Record it

Add the artifact link to the [reference index](../../reference.md) as `R1-05`.
