# 3. Document the Repository

## Objective

Give the repository enough context to be navigable by a newcomer.

## Steps

1. Write a README stating purpose, setup, and how to run tests.
2. List the commands a contributor runs most often.
3. Record naming, formatting, and layout conventions.
4. Ask an assistant to summarize the repository and check the summary for errors.

## Evidence of completion

A README from which a newcomer can reach passing tests unaided.
