# Round 1: MVP

Round 1 establishes the smallest practical AI-assisted delivery workflow. The objective is a baseline a team can repeat, review, and improve, not broad automation.

## Activities

1. [Environment Readiness Check](./activity-1.mdx)
2. [First Prompt to Working Code](./activity-2.mdx)
3. [Document the Repository](./activity-3.mdx)
4. [Write the First Test](./activity-4.mdx)
5. [Small Reviewable Change](./activity-5.mdx)
6. [Open a Pull Request](./activity-6.mdx)
7. [Validate and Record Evidence](./activity-7.mdx)
8. [Round 1 Retrospective](./activity-8.mdx)

## Completion standard

Work in a public or approved environment, preserve human review, and link tangible evidence
from the [reference index](../../reference.md).
