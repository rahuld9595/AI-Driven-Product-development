# 6. Open a Pull Request

## Objective

Practice writing a description that carries the review.

## Steps

1. Describe intent, affected components, risk, and validation performed.
2. Link the acceptance criteria.
3. Attach test output.
4. Request review and respond with traceable follow-up commits.

## Evidence of completion

A pull request whose description alone explains the change.

## Record it

Add the artifact link to the [reference index](../../reference.md) as `R1-06`.
