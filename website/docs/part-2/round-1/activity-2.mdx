# 2. First Prompt to Working Code

## Objective

Turn a one-sentence requirement into a running function.

## Steps

1. State the requirement in a single sentence.
2. Ask for the smallest implementation that satisfies it.
3. Run it and observe the actual output.
4. Note the gap between what you asked for and what you received.

## Evidence of completion

A working function plus a short note on what the prompt left ambiguous.
