# 7. Validate and Record Evidence

## Objective

Close the loop between work done and evidence kept.

## Steps

1. Run the full test suite and capture the result.
2. Record what was validated and what was not.
3. Add the artifact link to the reference index.
4. State any known gap explicitly rather than omitting it.

## Evidence of completion

An entry in the reference index pointing at a real artifact.

## Record it

Add the artifact link to the [reference index](../../reference.md) as `R1-07`.
