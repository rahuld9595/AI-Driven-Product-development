# 1. Environment Readiness Check

## Objective

Confirm the toolchain works end to end before writing anything.

## Steps

1. Install the prerequisites for your platform.
2. Run the assistant against a trivial prompt and confirm a response.
3. Clone the sample repository and run its test command.
4. Record any setup step that needed a workaround.

## Evidence of completion

A terminal transcript showing the sample test suite passing locally.

## Record it

Add the artifact link to the [reference index](../../reference.md) as `R1-01`.
