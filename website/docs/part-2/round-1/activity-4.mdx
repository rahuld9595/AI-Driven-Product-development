# 4. Write the First Test

## Objective

Establish a test harness and prove it fails when it should.

## Steps

1. Add one test that asserts current correct behavior.
2. Deliberately break the implementation and confirm the test fails.
3. Restore the implementation and confirm the test passes.
4. Document the test command in the README.

## Evidence of completion

A committed test plus evidence it fails on a real regression.
