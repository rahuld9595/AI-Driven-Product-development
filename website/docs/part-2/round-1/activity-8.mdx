# 8. Round 1 Retrospective

## Objective

Convert the round's friction into a durable guardrail.

## Steps

1. List every point where the assistant produced something wrong.
2. Classify each as missing context, missing constraint, or missing test.
3. Pick the single highest-value guardrail and write it down.
4. Carry that guardrail into Round 2.

## Evidence of completion

A written guardrail traceable to a specific observed failure.

## Record it

Add the artifact link to the [reference index](../../reference.md) as `R1-08`.
