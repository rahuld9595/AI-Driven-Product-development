# Docs & Activity Index

Use this page as the evidence register for the training. Every activity should link to a
version-controlled artifact: a pull request, test result, decision record, or other reviewable
outcome.

## Evidence standard

A completed activity answers four questions:

1. What problem or capability did the team address?
2. What artifact demonstrates the work?
3. How was it reviewed or validated?
4. What changed as a result?

## Updating the register

When an activity is completed, replace `Not started` with an accurate state and link the public
artifact. Do not link or copy confidential employer systems, internal tickets, source code, data,
or credentials.
