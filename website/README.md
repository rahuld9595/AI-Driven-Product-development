# Course site

The Docusaurus site for the AI-Driven Product Development training. Course content lives in
`docs/`; this directory holds the framework around it.

## Commands

```bash
npm install     # once
npm start       # dev server with hot reload
npm run build   # production build; fails on broken internal links
npm run serve   # serve the production build
npm test        # content checks: front matter, H1s, sidebar coverage
npm run typecheck
```

## Layout

```text
website/
|-- docs/                 Course content
|   |-- intro.md          Welcome
|   |-- proven-practices.md
|   |-- reference.md      Evidence register
|   |-- part-2/           The lab: rounds 1-3, overview, agent-ready repo
|   `-- setup/            Platform and tooling setup guides
|-- src/
|   |-- css/custom.css    Theme
|   `-- pages/index.tsx   Root redirect to the Welcome page
|-- static/               Assets served verbatim
|-- tests/                Content integrity checks
|-- docusaurus.config.ts
|-- sidebars.ts
`-- tsconfig.json
```

## Adding a page

1. Create the file under `docs/` with `id` and `title` front matter.
2. If it is outside an autogenerated directory, add its id to `sidebars.ts`.
3. Run `npm test` and `npm run build`.

Activity pages inside `part-2/round-*/` are picked up automatically and ordered by
`sidebar_position`, so a new activity needs no sidebar edit.
