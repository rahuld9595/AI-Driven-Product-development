Sustainable AI Practices

Practice Description
Planning Reduce ambiguity, surface risks early, and set the foundation before building.
Documentation Enable fast knowledge transfer and create the context for agent-driven work.
Implementation Translate ideas into working solutions through disciplined execution.
Testing Validate that what is built works as intended and catches regressions early.
Security Embed risk awareness into design, build, and validation through the PDLC.

Lost? Just ask in Claude Code

Requires this repository: The course-helping skill and training-guide agent are bundled with the course repo. To use them, clone it and run the agent.

If you get stuck or want to know where a concept is covered, just ask Claude Code naturally — there’s a course-helper skill that catches questions like:

  • “I’m stuck on activity 3, where do I start?”
  • “What’s plan mode and where do I learn about it?”
  • “What’s expected for this checkpoint?”

You can also invoke the underlying agent directly with @training-guide.
